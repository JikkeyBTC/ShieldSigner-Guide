# ShieldSigner OS

ShieldSigner OS provides the offline display and signing flow.<br> Keep installation and verification as separate steps.

## What this category covers

<div class="ss-summary-card">

### Installation

Download the image from the GitHub release, write it to microSD, and prepare for the first boot.

[Install ShieldSigner OS](./install)

</div>

<div class="ss-summary-card">

### Verification

Use the release's Bitcoin message signature and SHA-256 to check the integrity and source of the downloaded file.

[Verification guide](./verification)

</div>

<Callout type="warning" title="Do not write before verification">
Do not write the image to microSD or run it on the device until verification is complete.
</Callout>
