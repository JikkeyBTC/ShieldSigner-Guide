# Glossary

| Term | Meaning |
| --- | --- |
| Seed | Secret information used to recover a wallet. Do not leave it in documents or photos. |
| xpub | A public extended key used to derive addresses and watch balances. It cannot sign. |
| Descriptor | A description of a wallet's keys, derivation path, and script policy. |
| Watch-only | A wallet that manages addresses, balances, and transaction drafts using public information only. |
| PSBT | Partially Signed Bitcoin Transaction, a standard format for passing a transaction before and after signing. |
| UTXO | An unspent transaction output. |
| Change | An output returned to the wallet after a transaction. |
| PGP | A method for verifying a file signature and its author with a public key. |
| JavaCard | A Java-based platform for running small applets on secure card chips. |
| SeedKeeper | A JavaCard applet and card ecosystem that protects seeds and secrets with a PIN. |
