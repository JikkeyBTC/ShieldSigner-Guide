# Glossary

| Term | Meaning |
| --- | --- |
| Seed | Secret material that restores a wallet. Keep it offline. |
| xpub | Public extended key used to derive watch-only addresses. |
| Descriptor | A public policy and derivation description for a wallet. |
| Watch-only | A wallet that never holds signing keys. |
| PSBT | Partially Signed Bitcoin Transaction. |
| UTXO | An unspent transaction output. |
