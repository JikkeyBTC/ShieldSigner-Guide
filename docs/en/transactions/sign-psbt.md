# Review and sign a PSBT

A PSBT is an unsigned transaction draft. The watch-only wallet creates it; ShieldSigner checks the destination, amount, fee, change, and input total before signing.

Use QR or file transfer, confirm every page, and return the signed PSBT to the online wallet only after the review is complete.
