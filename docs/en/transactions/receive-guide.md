# Receive

In the Receive step, independently compare the address created by a watch-only wallet with the address shown on ShieldSigner.

## Flow

1. Open the receiving screen in BlueWallet or Coconut Wallet.
2. Send the address QR code or public string to ShieldSigner.
3. Check the network, account type, derivation path, and complete address.

<Callout type="warning" title="Do not send if the address differs">
If the address, network, or account type differs, stop receiving and investigate.<br> Do not use an address copied directly from search results or a message.
</Callout>
