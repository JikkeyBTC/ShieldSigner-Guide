# Loss and recovery plan

Keep more than one encrypted backup in separate secure locations. Decide in advance who can access a spare card and how a replacement device will be verified.

Recovery is a practiced procedure, not a promise that a lost PIN can be bypassed. Run a low-value restore test and update the plan when hardware or applet versions change.
