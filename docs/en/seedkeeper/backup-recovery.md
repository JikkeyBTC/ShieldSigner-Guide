# Using your card

Set a PIN on a new card, save a ShieldSigner seed, and load it again when you need it.<br> The card keeps the stored copy until you deliberately remove it.

<div class="ss-summary-card">

### 01 · Initialize the card and set a PIN

Complete the first setup for a new card.<br> If the card is already set up, use its existing PIN.

[Card initialization guide](./initialize)

</div>

<div class="ss-summary-card">

### 02 · Save a seed to the card

Choose a seed loaded in ShieldSigner, then enter the card PIN and a label.

[How to save a seed](./save)

</div>

<div class="ss-summary-card">

### 03 · Load a seed from the card

Read a saved seed and compare its fingerprint with the value recorded before saving.

[How to load a seed](./load)

</div>

<Callout type="info" title="Saving and loading move in opposite directions">
Saving moves a seed from ShieldSigner to the card.<br> Loading moves it from the card back to ShieldSigner, and does not delete the stored copy.
</Callout>
