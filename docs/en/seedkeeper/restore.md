# Restore a seed

Test recovery before an emergency, using a spare device with no funds and a verified OS image.

## Encrypted import

Use the official card flow, authenticate with the PIN, and import only the selected encrypted record.

## Plaintext import

Avoid plaintext export whenever possible. If a documented migration requires it, keep the process offline, erase temporary memory, and never photograph or paste the words.

Confirm the first derived address against an independent watch-only wallet before using the restored device.
