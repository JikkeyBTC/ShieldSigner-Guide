# Watch-only wallets

Watch-only wallets use only a public descriptor or xpub to show balances and receiving addresses.<br> Never enter a seed or private key in a wallet app.

<Callout type="warning" title="Enter public information only">
Do not enter a seed, PIN, or private key in a watch-only wallet.<br> Sharing an xpub or descriptor can reveal balances and transaction history, so share it carefully.
</Callout>
