# 시드 복원하기

복원은 장애가 발생한 뒤 처음 시도하지 말고, 카드 백업을 만든 직후 **자금이 없는 예비 장치**에서 시험하세요. 화면과 명령은 사용하는 버전에 따라 다르므로, 시드 단어를 직접 노출하지 않는지 먼저 확인합니다.

## 오프라인 복원 시험

1. 검증된 ShieldSigner OS가 설치된 예비 microSD와 장치를 준비합니다.
2. 네트워크를 끄고, 카드 리더와 복원에 필요한 장치만 연결합니다.
3. SeedKeeper 카드 PIN으로 인증한 뒤, 복원/가져오기 메뉴에서 암호화된 백업을 선택합니다.
4. 대상 지갑의 이름·지갑 지문·파생 경로를 확인합니다. 평문 시드를 요구하는 경우 화면을 촬영하거나 복사하지 말고, 주변에 사람이 없는지 확인합니다.
5. 복원이 끝나면 카드와 장치를 분리하고, 지갑 지문과 첫 수신 주소를 기존 워치온리 지갑에서 대조합니다.
6. 시험이 끝난 장치의 임시 데이터와 로그를 삭제하고, 테스트 시드였다면 실제 자금에 사용하지 않습니다.

<Callout type="warning" title="주소가 다르면 사용 중단">
지갑 지문·파생 경로·주소 중 하나라도 예상과 다르면 복원된 지갑을 사용하지 마세요. 카드와 ShieldSigner 버전, 경로 설정을 다시 확인하고 자금 이동 전 판매자나 공식 프로젝트 문서를 통해 원인을 확인합니다.
</Callout>

## 실제 장애 때

복구용 카드가 여러 장이면 하나씩 시도하되 PIN을 추측하지 마세요. 카드가 잠겼거나 애플릿이 손상된 경우 다른 카드와 별도 복구 수단을 사용하고, 복원된 지갑의 지문·주소를 확인한 뒤에만 거래를 재개합니다. 복원 후 기존 카드는 즉시 폐기하지 말고, 새 백업이 검증된 뒤 [복구 계획](./recovery)에 따라 교체합니다.

## 평문 가져오기와 암호화 가져오기

### 암호화 가져오기 (권장)

카드 간 보안 페어링으로 암호화된 백업을 대상 장치나 카드에 전달합니다. 전송 중 시드가 표시되지 않는지 확인하고 카드 ID·지갑 지문·파생 경로만 대조합니다.

### 평문 가져오기 (최후의 수단)

읽을 수 있는 시드 단어를 직접 입력하거나 평문 파일로 가져오는 방식입니다. 화면·키보드 기록·클립보드·로그에 남을 수 있어 카드 보호를 벗어납니다. 호환성 확인이 꼭 필요할 때만 오프라인·무인 환경에서 사용하고, 입력 직후 모든 임시 사본을 폐기합니다.

### 내보내기 형식 확인

복원 전에 원본 카드에서 내보내기 형식을 확인합니다. 암호화 내보내기는 대상 카드·장치와 페어링한 뒤 전달하고, 평문 내보내기는 시드가 노출되므로 복원 테스트 외에는 선택하지 않습니다. 화면에 `ENCRYPTED_EXPORT` 또는 `PLAINTEXT_EXPORT`처럼 형식이 표시된다면 기록만 남기고 시드 값 자체는 저장하지 마세요.
