# BTC 보내기

거래는 **온라인 워치온리 지갑에서 만들고, ShieldSigner에서 검토·서명**해요.<br> 여기서는 거래 초안인 PSBT를 만드는 부분까지 진행해요. [다음 페이지](./sign-psbt)에서 기기 검토부터 전송·확정까지 이어가요.

## 시작하기 전에

- [BTC 받기](./receive-guide)를 따라 지갑 연결과 내 주소를 확인해요.
- 온라인 지갑이 동기화되어 있고 사용할 잔액이 있는지 확인해요.
- 해당 지갑의 시드와 필요한 패스프레이즈를 ShieldSigner에 불러와요.
- 받는 사람과 **주소 전체·금액·네트워크**를 별도로 확인해요.
- 앱이 **서명 전 PSBT를 QR로 내보내고, 기기의 서명 QR을 읽는 기능**을 지원하는지 확인해요.

## 1. Send를 열어요 {#open-send}

온라인 지갑에서 **Send / 보내기**를 열어요.<br> 여러 지갑이 등록되어 있다면 ShieldSigner의 공개키로 연결한 지갑이 선택되어 있는지 확인해요.

워치온리 지갑에는 개인키가 없으므로 거래를 만들 수 있어도 혼자 서명할 수는 없어요.<br> 보내기를 위해 시드 단어나 개인키를 온라인 앱에 입력하라는 흐름으로 진행하지 마세요.

## 2. 받는 주소와 금액을 입력해요 {#recipient}

받는 주소 입력란에 상대방이 확인해 준 주소를 넣고 **전체 문자열**을 대조해요.<br> 복사·붙여넣기나 QR 읽기 뒤에도 주소가 바뀌지 않았는지 확인해요.

금액은 앱에 표시된 단위에 맞춰 입력해요.<br> **1 BTC = 100,000,000 sats**예요. 예를 들어 **20,000 sats는 0.0002 BTC**이며, 이는 단위 설명을 위한 숫자이지 권장 송금액은 아니에요.

<Callout type="warning" title="금액 단위와 네트워크를 확인해요">
받는 사람과 합의한 비트코인 메인넷 주소를 사용해요. 주소 형식만 보고 결제망까지 확인했다고 생각하지 마세요.<br> <strong>Max / 전액 보내기</strong>는 수수료를 제외한 사용 가능 금액을 모두 보낼 수 있어요. 의도한 경우에만 선택해요.
</Callout>

## 3. 수수료와 잔돈을 확인해요 {#fee}

거래는 아직 사용하지 않은 입금 단위인 **UTXO**를 입력으로 사용해요.<br> 선택한 입력에서 보낼 금액과 수수료를 빼고 남은 금액은 보통 내 지갑의 **잔돈(change) 주소**로 돌아와요.

**입력 합계 = 수신자에게 보내는 금액 합계 + 내 잔돈 + 네트워크 수수료**

예를 들어 입력이 100,000 sats이고 보낼 금액이 20,000 sats이면, 잔돈은 **80,000 sats에서 수수료를 뺀 값**이에요.<br> 실제 입력과 수수료는 내 거래에서 확인해야 해요. 지갑 전체 잔액을 매번 모두 입력으로 쓰는 것은 아니에요.

| 확인 항목 | 확인 방법 |
| --- | --- |
| 수수료율(sat/vB) | 거래 크기당 수수료예요. 온라인 지갑의 현재 추정치와 원하는 대기 시간을 참고해요. |
| 총수수료(sats 또는 BTC) | 실제로 지불할 금액이에요. 수수료율과 혼동하지 마세요. |
| 잔돈 | 남는 금액이 내 지갑으로 돌아오는지 확인해요. 기기에서도 잔돈 주소를 검증해요. |
| 선택한 입력 | 수동 코인 선택을 쓴다면 의도한 UTXO인지 확인해요. |

고정된 수수료율을 모든 거래에 적용하지 않아요.<br> 수수료가 예상보다 높거나 잔액이 부족하다면 거래를 만들기 전에 금액과 입력 선택을 다시 확인해요. 수수료 추정은 확정 시간을 보장하지 않아요.

## 4. 서명 전 PSBT를 표시해요 {#create-psbt}

온라인 지갑의 거래 미리보기에서 **수신자·금액·총수수료**를 확인해요.<br> 해당 앱의 **서명 전 거래 내보내기 / PSBT QR 표시** 기능을 선택해요. 앱에 따라 거래 생성과 내보내기가 별도 단계일 수 있어요.

<strong>PSBT(Partially Signed Bitcoin Transaction)</strong>는 거래 정보와 서명에 필요한 정보를 주고받는 형식이에요.<br> PSBT를 만들었다고 결제가 완료된 것은 아니고, 이 단계에는 아직 ShieldSigner의 서명이 없어요.

내보내는 QR이 **거래 PSBT**인지 확인해요.<br> 받는 주소 QR, 공개키 QR, SeedQR은 서로 용도가 달라요. 파일만 내보내는 앱이라면 임의의 웹 변환기에 올리지 말고, ShieldSigner와 호환되는 QR 교환 방법부터 확인해요.

## 5. 기기 카메라로 거래 QR을 읽어요 {#scan}

1. ShieldSigner 홈의 **Scan**을 열어요.
2. 온라인 지갑의 PSBT QR이 카메라에 들어오도록 거리와 각도를 맞춰요.
3. 움직이는 QR은 여러 프레임이 모두 읽힐 때까지 화면을 유지해요.
4. 시드 선택 또는 거래 개요 화면으로 넘어가면 읽기가 완료된 상태예요.

인식이 잘되지 않으면 화면 반사를 줄이고 QR 크기·화면 밝기·거리를 조절해요.<br> 계속 실패하면 앱의 QR 형식과 기기 지원 여부를 확인해요. 전송 문제를 해결하려고 시드 QR이나 개인키를 온라인 지갑에 넘기지 마세요.

**아직 승인하지 말고**, 다음 페이지에서 기기에 표시된 값을 하나씩 대조해요.
