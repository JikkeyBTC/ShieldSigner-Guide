# PSBT 검토·서명

[BTC 보내기](./send-guide)에서 만든 PSBT를 기기가 읽었다면, **기기에 표시된 내용을 직접 확인한 다음 서명**해요.<br> 이 페이지는 싱글시그 지갑의 QR 교환을 기준으로 해요. 서명·전송·확정은 각각 확인해야 하는 별도 단계예요.

## 1. 사용할 시드와 거래 개요를 확인해요 {#overview}

시드 선택 화면이 나오면 온라인 지갑에 연결한 시드를 선택해요.<br> 패스프레이즈를 쓰는 지갑이라면 같은 패스프레이즈가 적용되어 있어야 해요.

거래 개요에서 **입력 수, 수신자 수, 잔돈 출력 수**를 살펴보고 상세 검토로 넘어가요.<br> 모르는 수신자가 추가됐거나 예상과 다르게 잔돈이 없다면 계속 진행하지 말고 거래를 만든 지갑부터 확인해요.

기기가 해당 시드로 서명할 수 없다고 알리면 다른 시드를 무작정 선택하지 않아요.<br> 온라인 지갑의 공개키·지문·파생 경로와 기기에 불러온 시드·패스프레이즈가 맞는지 확인해요.

## 2. 목적지·금액·수수료·잔돈을 대조해요 {#review}

기기의 상세 화면을 순서대로 읽어요.<br> **컴퓨터나 휴대전화의 미리보기만 확인하고 기기 화면을 건너뛰면 안 돼요.**

| 확인 항목 | 무엇과 비교하나요? |
| --- | --- |
| 입력 합계 | 이 거래에 선택된 UTXO의 합계예요. 전체 지갑 잔액과 다를 수 있어요. |
| 받는 주소 | 받는 사람과 별도로 확인한 **주소 전체**와 비교해요. 여러 수신자라면 각각 확인해요. |
| 보낼 금액 | 요청한 금액과 단위가 맞는지 확인해요. |
| 네트워크 수수료 | 온라인 지갑의 미리보기에서 확인한 **총수수료**와 비교해요. sat/vB 수수료율과 혼동하지 않아요. |
| 잔돈 | 내 지갑으로 돌아오는 금액·주소·파생 정보와 기기의 주소 검증 결과를 확인해요. |

**입력 합계 − 수신자에게 보내는 금액 합계 − 잔돈 = 수수료**가 되는지 확인해요.<br> 잔돈 주소는 방금 입금에 쓴 주소와 다를 수 있어요. 문자열이 다르다는 이유만으로 오류는 아니지만, 기기가 내 지갑의 주소로 검증했는지 확인해야 해요.

<Callout type="danger" title="예상하지 못한 출력이나 경고가 있으면 서명하지 마세요">
잔돈이 있어야 하는 거래에서 <strong>Full Spend / No change</strong>가 나오거나, 잔돈 주소를 검증하지 못하거나, 모르는 출력이 있으면 중단해요.<br> 의도한 전액 보내기라면 잔돈이 없을 수 있어요. 경고를 없애려고 설정을 바꾸지 말고 거래가 내 의도와 맞는지 먼저 확인해요.
</Callout>

잘못된 내용이 있으면 승인하지 않고 온라인 지갑에서 거래를 수정해 새 PSBT를 만들어요.<br> 새로 만든 거래도 처음부터 다시 검토해 주세요.

## 3. 마지막으로 확인하고 서명해요 {#sign}

모든 값이 맞을 때만 최종 승인 화면에서 서명해요.<br> ShieldSigner가 **서명된 PSBT QR**을 표시하면 온라인 지갑에서 읽을 준비를 해요. 움직이는 QR이라면 읽기가 끝날 때까지 화면을 유지해요.

이때 기기는 네트워크에 거래를 전송하지 않아요.<br> 다만 서명된 거래를 가진 사람은 이를 전송할 수 있으므로, 승인 전 검토를 반드시 마치고 서명 QR을 공개적으로 공유하지 마세요.

## 4. 서명 QR을 온라인 지갑으로 반환하고 전송해요 {#broadcast}

1. 거래를 만든 온라인 지갑에서 해당 거래의 **서명 가져오기 / 서명된 PSBT 읽기** 기능을 열어요.
2. 컴퓨터나 휴대전화의 카메라로 ShieldSigner에 표시된 서명 QR을 읽어요.
3. 서명이 정상적으로 반영됐는지, 거래가 전송 가능한 상태인지 확인해요.
4. 수신자·금액·총수수료를 마지막으로 대조한 뒤 **Broadcast / 전송**해요.

넘기는 것은 **서명된 거래**예요. 시드 QR·개인키·카드 PIN을 전달하는 단계가 아니에요.<br> 앱에 따라 서명 가져오기 뒤 곧바로 전송할 수 있으므로, 사용 중인 앱의 전송 동작을 미리 확인해요.

서명을 읽지 못한다면 같은 거래의 가져오기 화면인지, 호환되는 QR 형식인지 확인해요.<br> 서명이 부족하다는 메시지가 나오면 원인을 확인하고, 완료시키기 위해 시드 단어를 온라인에 입력하지 않아요.

## 5. 전송 결과와 확정을 확인해요 {#confirmation}

온라인 지갑의 전송 결과와 거래 내역에서 **TXID**를 확인해요.<br> TXID는 거래를 구분하는 64자리 16진수 식별자예요. **TXID가 있다는 것만으로 전송이나 확정이 증명되지는 않아요.** 거래를 만들 때 미리 표시하는 앱도 있어요.

| 단계 | 확인할 내용 |
| --- | --- |
| 전송 결과 | 온라인 지갑이 전송 성공을 알렸는지, 오류가 있는지 확인해요. |
| 미확정 거래 | 동기화된 지갑이나 같은 네트워크의 거래 조회 도구에서 거래가 조회되는지 확인해요. |
| 블록 포함 | 블록 정보와 확정 수가 표시되는지 확인해요. |
| 결제 완료 판단 | 받는 사람이나 서비스가 요구하는 확정 수에 도달했는지 확인해요. |

외부 거래 조회 서비스를 쓴다면 시드나 개인키가 아니라 **TXID만** 입력해요.<br> 조회한 거래의 주소·금액·수수료도 내 거래와 맞는지 확인해요. 외부 서비스에는 조회 정보가 전달될 수 있어요.

### 확정이 늦거나 전송 오류가 나면

- 같은 네트워크와 TXID를 조회하는지, 지갑이 동기화됐는지 확인해요.
- 미확정 상태라면 수수료와 네트워크 혼잡을 확인해요. 예상 시간은 보장이 아니에요.
- 오류가 났더라도 기존 거래 상태부터 확인해요. 새 거래를 무작정 반복 생성하면 중복 지급할 수 있어요.
- 수수료 조정 기능을 쓰면 변경된 거래 내용을 다시 확인해요. 추가 서명이 필요하다면 새 PSBT도 기기에서 다시 검토해요.
- 화면을 닫거나 기기를 껐다고 이미 전송한 거래가 취소되지는 않아요.

## 6. 사용을 마쳐요 {#finish}

온라인 지갑이 서명된 거래를 정상적으로 가져온 것을 확인한 뒤에는 기기를 계속 켜 둘 필요가 없어요.<br> 사용한 시드는 **Discard seed**로 기기 메모리에서 비우거나 기기를 정상 종료해요. 확정 상태는 온라인 지갑에서 계속 조회할 수 있어요.

카드를 빼는 것만으로 이미 기기 메모리에 불러온 시드가 지워지지는 않아요.<br> **Discard seed는 SeedKeeper 카드에 저장한 시드를 삭제하는 기능이 아니에요.** 카드 초기화나 저장 항목 삭제와 혼동하지 마세요.
