# 용어집

| 용어 | 뜻 |
| --- | --- |
| Seed | 지갑을 복구하는 비밀 정보. 문서나 사진으로 남기지 않습니다. |
| xpub | 주소를 생성하고 잔액을 감시할 수 있는 공개 확장키. 서명은 할 수 없습니다. |
| Descriptor | 키와 파생 경로, 스크립트 정책을 표현하는 지갑 설명자입니다. |
| Watch-only | 공개 정보만으로 주소·잔액·거래 초안을 관리하는 지갑입니다. |
| PSBT | Partially Signed Bitcoin Transaction. 서명 전후 거래를 전달하는 표준 형식입니다. |
| UTXO | 아직 소비되지 않은 거래 출력입니다. |
| Change | 거래 후 지갑으로 돌아오는 잔돈 출력입니다. |
| 비트코인 메시지 서명 | 해당 주소의 키 보유자가 특정 메시지에 서명했는지 확인하는 방식입니다. 주소가 누구의 것인지는 별도로 확인해야 합니다. |
| SHA-256 | 파일의 내용에서 계산한 64자리 해시값입니다. 서명을 검증한 목록의 값과 비교해 파일의 일치 여부를 확인합니다. |
| JavaCard | 카드형 보안 칩에서 작은 애플릿을 실행하는 Java 기반 플랫폼입니다. |
| SeedKeeper | JavaCard에서 시드와 비밀을 PIN으로 보호하는 애플릿/카드 생태계입니다. |
