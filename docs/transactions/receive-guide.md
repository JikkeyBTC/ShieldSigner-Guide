# Receive

Receive 단계에서는 워치온리 지갑에서 만든 주소를 ShieldSigner 화면과 독립적으로 대조합니다.

## 흐름

1. BlueWallet 또는 Coconut Wallet에서 수신 화면을 엽니다.
2. 주소 QR 또는 공개 문자열을 ShieldSigner로 전달합니다.
3. 네트워크, 계정 유형, 파생 경로와 주소 전체를 확인합니다.

<Callout type="warning" title="주소가 다르면 전송하지 마세요">
주소·네트워크·계정 유형 중 하나라도 다르면 입금을 중단하고 원인을 확인합니다. 검색 결과나 메신저로 받은 주소를 그대로 사용하지 마세요.
</Callout>
