# 분실과 복구 계획

SeedKeeper는 복구를 쉽게 만들어 주지만, 분실·파손·PIN 잠금 위험을 없애지는 않습니다. 카드 A 하나에 모든 복구 가능성을 맡기지 말고, 서로 다른 장소에 카드 B와 별도 복구 수단을 보관하세요.

## 권장 계획

| 상황 | 즉시 할 일 | 다음 단계 |
| --- | --- | --- |
| 카드 한 장 분실 | 남은 카드의 PIN·메타데이터 확인 | 분실 카드가 회수돼도 새 카드로 교체하고 복제 |
| PIN 반복 실패/잠금 | 더 이상 추측 입력 금지 | 다른 카드로 복원 시험, 공식 잠금 정책 확인 |
| 카드 손상 | 리더·케이블부터 교차 확인 | 정상 카드로 복원 후 새 백업 생성 |
| 백업 불일치 | 거래·주소 사용 중단 | 카드 ID·지갑 지문·파생 경로를 재검증 |

## 다중 카드 운영

1. 최소 두 장을 별도로 보관하고 카드 ID를 평문 시드 없이 기록합니다.
2. [카드 간 복제](./clone) 후 각 카드에서 메타데이터와 [복원 시험](./restore)을 확인합니다.
3. 일정 주기 또는 카드 교체 때 새 카드에 암호화 복제를 수행합니다.
4. 폐기할 카드는 공식 삭제·초기화 절차를 따르고, PIN·복구 기록과 함께 버리지 않습니다.

<Callout type="danger" title="분실 카드를 찾았어도 바로 재사용하지 마세요">
분실 기간에 누군가 PIN을 알았거나 카드를 변조했을 가능성을 배제할 수 없습니다. 회수한 카드는 신뢰 경계에서 제외하고, 정상 카드로 복원한 뒤 새 카드 세트로 교체하는 편이 안전합니다.
</Callout>

## 복구 기록에 남길 것

- 카드 별칭과 마스킹된 ID(예: `CARD_ID_01`)
- SeedKeeper 애플릿 버전과 마지막 검증일
- 백업한 지갑의 지문·파생 경로(시드 단어는 제외)
- 카드 보관 장소와 담당자, 교체 예정일
- PIN을 입력하지 않고도 따라갈 수 있는 복원 순서

복구 기록 자체가 시드가 되지 않도록 하고, 사진·클라우드 메모·채팅에는 저장하지 마세요. 자세한 백업 흐름은 [시드를 카드에 백업하기](./backup), 개념은 [SeedKeeper란?](./what-is-seedkeeper)을 다시 확인합니다.
