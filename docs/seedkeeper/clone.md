# 카드 간 복제

복제는 카드 A의 백업을 카드 B에 추가로 보관하는 절차입니다. 카드 B는 새 카드로 초기화하고, 카드 A와 B의 식별자를 작업 전에 적어 두세요.

## 안전한 페어링

1. [카드 초기화](./initialize)를 카드 B에서 완료하고 새 PIN을 설정합니다.
2. 신뢰할 수 있는 오프라인 컴퓨터에서 카드 A와 B만 연결합니다. 원격 지원·화면 공유는 끕니다.
3. SeedKeeper가 제공하는 카드 간 백업/복제 기능을 선택하고 두 카드의 ID를 각각 확인합니다.
4. 카드가 요구하는 보안 페어링 또는 상호 확인 코드를 양쪽에서 대조합니다. 코드가 다르면 취소합니다.
5. 평문 추출 대신 암호화된 카드 간 전송을 선택합니다.
6. 완료 후 두 카드에서 시크릿 이름·지갑 지문·생성 시각 같은 메타데이터만 조회해 일치 여부를 확인합니다.

<Callout type="danger" title="복제 파일과 평문을 만들지 마세요">
복제가 파일 내보내기를 요구하는 경우에도 암호화된 형식만 사용하고, 평문 파일·클립보드·터미널 로그를 남기지 마세요. 기능이 평문만 제공한다면 자금이 없는 테스트 시크릿으로 먼저 절차를 평가하고 공식 지원 문서를 확인합니다.
</Callout>

## 복제 후 시험

- 카드 B를 분리했다가 다시 연결해 PIN 인증과 목록 조회가 되는지 확인합니다.
- 카드 A를 잠시 보관한 뒤 카드 B만으로 [예비 장치 복원](./restore)을 실행합니다.
- 복원된 지갑의 지갑 지문과 예상 수신 주소가 일치하는지 확인합니다. 자금을 보내는 테스트는 소액으로 별도 판단합니다.

카드 B가 정상이어도 카드 A를 즉시 폐기하지 마세요. 보관 위치를 분리하고, 교체·폐기 시에는 [복구 계획](./recovery)에 따라 처리합니다.
