# 보안 모델과 사고 대응

ShieldSigner는 시드와 서명 키를 네트워크 연결 장치에서 분리하는 도구입니다. 안전성은 기기 검증, 백업 보호, 거래 확인이 함께 지켜질 때 성립합니다.

## 우리가 줄이는 위험

- 워치온리 앱과 온라인 컴퓨터가 개인키를 보지 않도록 격리
- PSBT에서 목적지·금액·수수료를 독립 화면으로 확인
- SeedKeeper 카드에 암호화된 백업을 보관

## 남아 있는 위험

악성 또는 변조된 OS 이미지, 잘못된 주소 확인, PIN 노출, 피싱 앱, 백업 분실은 여전히 사용자 책임 범위에 남습니다. 공식 릴리스와 서명을 확인하고, 실제 자금을 넣기 전 소액으로 복구 시험을 하세요.

## 불일치·훼손 대응

이미지 해시/PGP가 맞지 않거나, 포장·부품·화면이 안내와 다르거나, 주소가 앱과 ShieldSigner에서 다르면 즉시 전원을 끄고 사용을 중단합니다. 시드나 PIN을 누구에게도 보내지 말고 판매자에게 증상과 검증 결과만 문의하세요. 의심되는 기기에서 새 거래에 서명하지 않습니다.

<Callout type="warning" title="시드가 노출된 것 같다면">해당 시드는 더 이상 안전하다고 가정하지 말고, 신뢰할 수 있는 새 지갑으로 자금을 이동하는 계획을 세우세요. 기존 카드를 계속 재사용하지 마세요.</Callout>
